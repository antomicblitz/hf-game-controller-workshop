# Controller firmware

This copy-ready firmware is for the Adafruit Feather nRF52840 Sense (PID 4516).

- CircuitPython: 10.3.0 en_US
- Board ID: `nRF52840-Feather-Sense`
- [Download the validated UF2](https://downloads.circuitpython.org/bin/feather_bluefruit_sense/en_US/adafruit-circuitpython-feather_bluefruit_sense-en_US-10.3.0.uf2)
- SHA-256: `61c9d670d0ed5706af0dbf1fe3b180c43697094f0cf2b1c40f651735e4af7556`

After installing the UF2, copy the **contents** of `CIRCUITPY/` to the root of
the board's `CIRCUITPY` drive. Do not copy the outer folder itself.

See [Wiring and firmware](../docs/04-wiring-and-firmware.md) for the complete
student procedure.
