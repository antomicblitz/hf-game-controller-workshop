# Third-party software

This repository depends on separately licensed open-source packages listed in
`pyproject.toml`. It loads these pinned browser libraries from their public CDN:

- [Three.js](https://github.com/mrdoob/three.js), MIT License, version 0.180.0.
- [model-viewer](https://github.com/google/model-viewer), Apache License 2.0,
  version 3.5.0.

No vendor CAD files, component models, or CircuitPython binaries are copied
into this repository. The firmware guide links to the official Adafruit image.
